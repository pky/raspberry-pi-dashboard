# Raspberry Pi Dashboard - 設計書 (メイン索引)

## 📋 概要

RaspberryPi5上で動作するタッチパネル対応の多機能ダッシュボードシステム。PyQt5ネイティブGUIとFlask Webダッシュボードのハイブリッド構成で、SHT35センサーからの高精度温湿度データ（±0.2°C）、MH-Z19E CO2センサーからの空気質データ、およびGoogle Calendar APIからのカレンダーデータを統合表示。M.2 SSD超高性能化とサービスアカウント完全自動化を実現した次世代IoTシステム。

## 🏗️ システム全体像

```
[タッチパネル] ← 直接実行 → [PyQt5 Native GUI] ← API → [Flask Server]
                                                              ↓
              ← HTTP → [Chromium Browser] ← Web → [Flask Server] → [Google Calendar API]
                                                              ↓            ↓
[RaspberryPi5] → [SHT35センサー] ← I2C ← [Flask Server] → [サービスアカウント] → [個人予定]
     ↓         → [MH-Z19E CO2] ← UART ←        ↓                    ↓
[M.2 SSD] → [超高性能ストレージ] ← [50,252スコア] ← [システム最適化] → [PC級性能]
     ↓
[systemd監視] → [自動再起動] ← [cron監視] ← [ヘルスチェック]
```

## 📊 **現在のシステム状況**

### 🔋 **電源・ハードウェア**
- **メイン電源**: 65W ACアダプター
- **タッチパネル**: 独立USB電源（過電流対策）
- **M.2 SSD**: KIOXIA KBG40ZNS256G (256GB) - 超高性能稼働中
- **センサー**: SHT35 (I2C) + MH-Z19E CO2 (UART GPIO14/15)

### 🖥️ **ソフトウェア構成**
- **OS**: Raspberry Pi OS 64-bit (M.2 SSDルート)
- **Python**: 3.11 + Flask + PyQt5
- **認証**: Google Calendar サービスアカウント
- **監視**: systemd + cron + 自動テスト

- **電源制限**: なし (throttled=0x0)
- **メモリ使用**: 9.1% (正常範囲)
- **API成功率**: 100% (全7エンドポイント)
