# API設計書 - Raspberry Pi Dashboard

## 📋 概要

Raspberry Pi Dashboard システムのFlask APIエンドポイント設計書。システム監視、センサーデータ、カレンダー、データベース管理、ストレージ監視まで包含する包括的API仕様。

**最終更新**: 2025年8月20日  
**APIバージョン**: v2.0 - SQLiteデータベース管理統合版  
**エンドポイント数**: 全24個

## 🎯 API設計思想

- **RESTful設計**: HTTP標準ステータス・メソッドに準拠
- **統一レスポンス形式**: 全エンドポイント共通のJSONレスポンス構造
- **パフォーマンス監視**: 全APIで自動的にレスポンス時間・エラー率を記録
- **エラーハンドリング**: 統一されたエラーレスポンスとログ記録
- **セキュリティ**: SQLite直読み・パラメータ検証・SQLインジェクション対策

## ⚡ 重要API詳細仕様

### 1. `/api/metrics/range/<range_type>` (NEW - Chart.js統合)

**目的**: Chart.jsグラフ表示用のSQLite直読みデータ提供  
**SQLite統合**: 月次ローテーションDBから複数月データ自動統合

#### パラメータ
- `range_type`: `1h`, `6h`, `12h`, `24h`

#### レスポンス例
```json
{
  "status": "success",
  "data": {
    "metrics": [
      {
        "timestamp": "2025-08-20T21:26:29.046520",
        "co2_ppm": 706,
        "room_temperature": 26.6,
        "humidity": 62.8,
        "cpu_percent": 0.0,
        "memory_percent": 14.1,
        "cpu_temperature": 48.0,
        "disk_used_gb": 9.1,
        "disk_percent": 3.9
      }
    ],
    "total_points": 2,
    "time_range": "1h",
    "time_range_hours": 1,
    "data_source": "sqlite_direct",
    "last_updated": "2025-08-20T21:27:00.927153"
  }
}
```

### 2. `/api/database/status` (NEW - 容量管理)

**目的**: SQLiteデータベース容量・保存期間の監視

#### レスポンス例
```json
{
  "status": "success",
  "data": {
    "file_sizes_mb": {
      "co2": {"2025-08": 0.02},
      "temp_humidity": {"2025-08": 0.01}
    },
    "total_sizes_mb": {"co2": 0.02, "temp_humidity": 0.01},
    "grand_total_mb": 0.03,
    "available_months": {
      "co2": ["2025-08"],
      "temp_humidity": ["2025-08"] 
    },
    "retention_months": 6,
    "cleanup_months": 7,
    "current_month": "2025-08"
  }
}
```

### 3. `/api/sensor` (統合センサー)

**目的**: SHT35（温湿度）+ MH-Z19E（CO2）統合データ

#### レスポンス例

```json
{

    "temperature": 26.6,
    "humidity": 62.8,
    "discomfort_index": 75.4,
    "comfort_level": "不快",
    "co2_ppm": 706,
    "co2_level": "正常",
    "co2_color": "green",
    "co2_icon": "✓",
    "co2_message": "",
    "co2_simulation": true,
    "sensor_types": ["SHT35", "MH-Z19E"],
    "location": "室内",
    "timestamp": "2025-08-20T21:26:29.071874"
  }
}
```

## 🛡️ セキュリティ・パフォーマンス仕様

### SQLインジェクション対策
- **パラメータ化クエリ**: 全SQLクエリでプレースホルダ使用
- **入力検証**: 時間範囲・日付形式の厳格チェック
- **ファイルパス検証**: パストラバーサル攻撃防止

### パフォーマンス最適化
- **インデックス活用**: timestamp列への自動インデックス
- **接続プール**: SQLite接続の効率的管理
- **キャッシュ戦略**: 頻繁アクセスデータのメモリキャッシュ
- **並列処理**: 複数APIエンドポイントの同時処理対応

### エラーハンドリング
- **統一エラー形式**: 全APIで一貫したエラーレスポンス
- **詳細ログ記録**: エラー内容・スタックトレース・コンテキスト情報
- **グレースフル復旧**: センサー読み取り失敗時の自動フォールバック

## 📈 パフォーマンス監視

### 自動メトリクス収集
- **レスポンス時間**: 全エンドポイントの応答時間記録
- **エラー率**: HTTP 4xx/5xx エラー率の追跡  
- **スループット**: 秒間リクエスト数・同時接続数
- **リソース使用量**: CPU・メモリ・ディスクI/O監視

### アラート閾値
- **レスポンス時間**: 目標時間の2倍を超過で警告
- **エラー率**: 5%超過で警告、10%超過で緊急
- **データベースサイズ**: 50MB/月を超過で警告
- **ディスク容量**: 90%使用で警告、95%使用で緊急
