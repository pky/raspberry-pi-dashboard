## 🔧 設定情報まとめ

### バックアップ先設定
- **ローカル**: `/opt/raspberry-pi-backups/home-backup/`
- **NAS**: `smb://nas.local/backup/raspberry-pi-home/` (マウント先: `/mnt/nas_backup`)
- **認証**: username=backup, password=（設定値）

### ソースディレクトリ（ホームディレクトリ全体）
- **メイン**: `/home/pi/` (ホームディレクトリ全体・2.7GB)
  - `projects/raspberry-pi-dashboard/` - プロジェクトファイル
  - `.ssh/` - SSH鍵・設定
  - `.bashrc`, `.profile` - シェル設定
  - `bin/`, `Desktop/` - ユーザー環境
- **システム設定**: `/etc/systemd/system/raspberry-pi-*.service`
- **ログ設定**: `/etc/logrotate.d/raspberry-pi-dashboard`

### 除外パターン（容量効率化）
- キャッシュ: `.cache/`, `.dbus/`
- 履歴: `.bash_history`, `.python_history`
- 一時ファイル: `*.log`, `__pycache__/`, `*.pyc`
- 既存バックアップ: `backups/`, `backup_*`
