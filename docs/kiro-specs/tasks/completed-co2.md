## 🔬 **技術詳細・実装仕様**

### **MH-Z19Eセンサー仕様**
```python
# センサー仕様
測定方式: NDIR (Non-Dispersive Infrared)
測定範囲: 0-10,000ppm  
精度: ±(50ppm + 3% of reading)
動作温度: 0-50°C
動作湿度: 0-95% RH
応答時間: T90 < 120s
安定時間: 3分
寿命: >5年
```

### **通信プロトコル詳細**
```python
# CO2読み取りコマンド
CMD = [0xFF, 0x01, 0x86, 0x00, 0x00, 0x00, 0x00, 0x00, 0x79]

# レスポンス形式 (9 bytes)
[0xFF, 0x86, HIGH, LOW, TEMP, STATUS, 0x00, 0x00, CHECKSUM]
# HIGH, LOW: CO2濃度 (ppm = HIGH*256 + LOW)
# CHECKSUM: CRC8検証
```
